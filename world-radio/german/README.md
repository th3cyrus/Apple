# German Radio

An independent, language-based selection of **5 nonreligious radio stations** from multiple countries and streaming platforms.

**Primuse subscription:**

```text
https://raw.githubusercontent.com/th3cyrus/Apple/main/world-radio/german/radio.m3u
```

Station country codes identify broadcaster listings; they do not restrict language-based grouping to a single country. The list focuses on music, news, culture and talk. Dedicated religious programming is excluded.

| Station | Country code | Programming |
| --- | --- | --- |
| ByteFM | DE | Music Discovery |
| Deutschlandfunk | DE | News & Culture |
| Deutschlandfunk Kultur | DE | Culture & Talk |
| JazzRadio Berlin | DE | Jazz |
| FM4 | AT | Alternative & Electronic |
