# U.S. Radio Directory for Primuse

4,534 distinct U.S. stations from Radio Browser, split into 12 independent subscriptions. Import each desired M3U URL into Primuse.

**Important:** These are crowd-sourced directory links and NOT individually verified audio streams. Radio Browser's check is not a playback test from Iraq or a guarantee against geo-blocking. The original 36-station [curated playlist](../radio.m3u) remains separate.

Only HTTPS entries with acceptable URL structure are included. No broken, HTTP-only, mismatched double-extension, or known-bad directory entries are intentionally imported. This cannot cover every U.S. broadcast station.
