# Expanded U.S. Radio Directory for Primuse

The full directory shards are produced by the
[U.S. Radio Directory Refresh](../.github/workflows/us-directory.yml) workflow
on the main branch. Links to 12 parts will appear below after its first
successful run. Import each desired part as a separate Primuse subscription;
Primuse caps each subscription at 1,000 stations.

[Featured HTTPS directory preview](https://raw.githubusercontent.com/th3cyrus/Apple/main/us-directory/featured.m3u): **128**
listed U.S. stream URLs filtered for HTTPS and basic URL safety. This preview
is directory-derived, **not** audio-decoder-verified.

The 36 curated stations and their matching custom station covers remain in
[the main playlist](../radio.m3u). Station favicon images in this supplemental
directory come from the broadcasters and may not follow the curated design.

**Coverage:** Only stations listed by Radio Browser as United States and
last-checked-good, with safe HTTPS URLs, are eligible. This does not mean
all over-the-air American stations are available online, that every directory
stream works in Primuse, or that a stream is accessible from Iraq.
