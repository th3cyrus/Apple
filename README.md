# Primuse · USA Real Radio 📻

Personal 35-station radio playlist, with self-hosted radio artwork and optional GitHub auto-refresh.

## GitHub setup for iPhone

Repository: https://github.com/th3cyrus/Apple

1. On the GitHub website, create or replace `.github/workflows/import.yml` with the entire contents of `Primuse_Apple_Workflow.txt` provided separately. Commit the workflow to the default branch.
2. Upload **the ZIP file itself** (`Primuse_Apple_Import.zip`) to the repository root using Add file → Upload files. Commit it. Do **not** unzip it on iPhone.
3. In Actions, open **Primuse Import and Refresh**. The import job unpacks the ZIP directly into the repository root, generates GitHub artwork URLs, removes the uploaded ZIP, and commits the files.
4. If import cannot push, check Settings → Actions → General → Workflow permissions. The workflow requests `contents: write`, but repo or org settings can restrict it.
5. After the import finishes, go to Actions → Primuse Import and Refresh → Run workflow to test a full refresh. Scheduled updates run Wednesdays at 03:17 UTC.

**Primuse subscription URL:**

`https://raw.githubusercontent.com/th3cyrus/Apple/main/radio.m3u`

In Primuse, select Radio → + → Add Subscription and paste the URL. The app controls its own refresh schedule and might require you to refresh the subscription manually.

## Project files

- `stations.json`: the editable station catalog (35 entries).
- `radio.m3u`: playlist regenerated by the workflow.
- `logos/`: artwork for all 35 stations.
- `scripts/update.py`: guarded stream and artwork refresher.
- `.gitignore`: normal Git ignore rules.
- `.github/refresh_original.yml.txt`: backup of the original separate refresh workflow. It is kept as `.txt` because the import bot may lack permission to create a second runnable workflow. The **active** combined importer/refresh scheduler is `.github/workflows/import.yml`, which you created directly on GitHub.

## Important notes

- Stream links can break or be geo-blocked; verification from GitHub's servers does not guarantee playback on every network.
- The updater waits for repeated failures before cautiously replacing an eligible stream.
- Do not bypass HTTPS certificate verification.
